# Row-Matrix

https://row-matrix.onrender.com

**Predominant Language:**  
Python

**Purpose:**  
As a Division I rower, I have wanted to create something that athletes can depend on instead of having to calculate their workout projections mentally. This inspired me to develop Row-Matrix, a Python-based project designed to help athletes better understand their performance and workout goals.

**Reason:**  
Row-Matrix allows athletes of all experience levels to estimate their projected test piece times. Using the Concept2 formula, I developed a way to calculate seconds per meter and use that information to estimate the time it would take an athlete to complete their preferred test piece distance.

**Goal:**  
With this project, I hope to give athletes more confidence going into test pieces and workouts. Row-Matrix is designed to help athletes recognize their capabilities, set realistic goals, and better understand what they can work toward accomplishing.
