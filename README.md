# Row-Matrix
# 🏁 Row-Matrix | Rowing Performance Tracker

**Row-Matrix is a rowing performance tracking application designed to help rowers record workouts, monitor performance, and track their progress over time.**

The goal of Row-Matrix is to bring workout logging, performance analytics, and training history together in one place. By organizing workout data, athletes can better understand their training and work toward their personal goals.

---

## 🚣 About the Project

As a rower, tracking performance is an important part of training. Row-Matrix aims to make it easier for athletes to record workouts, review previous sessions, and understand their progress.

The application is being developed with the goal of providing a centralized platform for rowing performance data, including workout distance, duration, pace, and heart rate.

Row-Matrix is an ongoing personal software development project focused on combining athletics, data tracking, and software engineering.

---

## 🎯 Project Goals

- Create a simple and accessible workout tracking experience.
- Allow athletes to record and organize rowing workouts.
- Track workout distance, duration, and performance metrics.
- Maintain a history of previous workouts.
- Visualize training progress through statistics and charts.
- Explore heart-rate-based training analysis.
- Build a foundation for future athlete profiles and wearable-device integrations.

---

## ✨ Planned Features

### Workout Logging
- Record workout distance and duration.
- Organize workouts by date and workout type.
- Support tracking for erg workouts and on-water sessions.

### Performance Tracking
- Calculate average split per 500 meters.
- Monitor total distance rowed.
- Compare results across workouts.
- Track personal progress over time.

### Heart Rate Analysis
- Record average and maximum heart rate.
- Explore heart-rate-based training zones.
- Support analysis of training intensity.

### Workout History
- Review previously recorded workouts.
- Compare workout statistics.
- Maintain an organized training log.

### Athlete Dashboard
- Display workout summaries.
- Show total distance and completed workouts.
- Present performance trends through charts.
- Provide a central location for training statistics.

### Future Development
- User accounts and personalized profiles.
- Database integration for persistent workout storage.
- Interactive performance visualizations.
- Potential integration with compatible fitness devices and health data sources.
- Personal goal setting and progress tracking.

## 🚀 Getting Started

### Prerequisites

To view and work on the project, you will need:

- [Visual Studio Code](https://code.visualstudio.com/)
- A modern web browser.
- The Live Server extension for VS Code.

Python will be needed when Python-based functionality is introduced.

### Installation

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Open the project folder in Visual Studio Code.

3. Open `index.html`.

4. Click **Go Live** to launch the website in your browser.

Replace `YOUR_GITHUB_REPOSITORY_URL` with the actual HTTPS URL of your GitHub repository.
